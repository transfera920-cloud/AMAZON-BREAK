## 社群分享預覽圖（og:image）說明
本專案已於 `index.html` 設定社群分享圖片標籤（Open Graph 及 Twitter Card）：
- 預期路徑：`public/og-cover.jpg`（部署後路徑為 `https://amazon-hike.com/chapter20/og-cover.jpg`）
- 建議尺寸：**1200 × 630 像素**（1.91:1 比例）
- 圖片主旨：隊伍分流管理教案｜亞馬遜國家山岳協會

請將設計好的 `og-cover.jpg` 圖檔直接置入 `public/og-cover.jpg`，專案在建置時會自動複製至發布目錄。
